# Security policy

## Project status

This repository is pre-alpha. It has no supported release line, stable contract,
production-readiness claim, or certification claim. Bootstrap validation covers
only repository-local contract and fixture behavior.

## Reporting a vulnerability

Use GitHub private vulnerability reporting:

<https://github.com/itdojp/crypto-communications-assurance/security/advisories/new>

Do not include suspected vulnerabilities, exploit details, secrets, customer data,
production evidence, or raw audit evidence in a public Issue, Discussion, pull
request, commit, or fixture.

Provide only the minimum information needed to reproduce the report safely:

- affected revision or future released version;
- observed behavior and impact;
- a minimal non-production reproduction where safe;
- environmental assumptions;
- whether any material is sensitive and requires restricted handling.

Do not probe production, staging, or an external host. Do not send private evidence
to an unreviewed external model or scanner.

## Triage boundary

A report, scanner result, model output, test failure, or formal-tool result is not
automatic vulnerability confirmation. A human security maintainer reviews the
evidence, determines disclosure handling, and makes any risk or release decision.
The absence of a finding does not prove the absence of vulnerabilities.

No automatic disclosure or publication process is enabled.
